# Mission

## When human-linked data creates value, who should benefit?

The digital economy routinely creates value from human creativity,
contribution, attention, behaviour and relationships.

Too often, that value becomes disconnected from the people who created
it.

Creators can be under-credited.

Rights holders can be underpaid.

Collectors and communities can help create cultural value without
visibility or participation.

Audiences generate behavioural and emotional signals that are often
captured without meaningful understanding, control or benefit.

Creator Rights Network exists to help build a better alternative.

## Our Position

We believe the next phase of digital infrastructure must distinguish
between data that should become more visible because visibility creates
fairness, and data that should be protected because connection creates
risk.

### Public attribution data should become more visible

- Creator credits
- Contribution history
- Ownership relationships
- Licensing information
- Provenance records
- Value flows

### Personal data should receive stronger protection

- Behavioural data
- Emotional signals
- Identity-linked profiling
- Biometric data
- Sensitive personal information

The goal is not radical openness.

The goal is accountable connection.

## Our Five Principles

### 1. Attribution is infrastructure

Credit, provenance and contribution data support discovery, licensing,
reputation, remuneration and cultural memory.

### 2. Rights data creates trust

Ownership and licensing transparency help works be valued, exchanged,
licensed and collected with confidence.

### 3. Connected data reveals hidden value

Value becomes more visible when works are connected to creators,
provenance, context, collectors and audiences.

### 4. Personal data requires dignity-first protection

Behavioural, emotional and identity-linked data should not be treated
as free raw material simply because it can be captured.

### 5. Fair participation requires informed choice

People deserve visibility, agency and participation when human-linked
data creates value.

## Why Music?

Music is our first proof case because it makes these relationships
visible.

One missing credit can erase labour.

One broken ownership link can block payment.

One private dataset can concentrate power.

Music demonstrates that attribution is not administrative overhead.

Attribution is value infrastructure.

## Guiding Principle

Make value visible where visibility creates justice,
and protected where visibility creates risk.
